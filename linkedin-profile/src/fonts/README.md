# Fonts

- **Lora** (Bold, Regular) — display / the business name
- **Work Sans** (Bold, Regular) — supporting text

Both are licensed under the SIL Open Font License 1.1. The full licence text ships
alongside them in `Lora-OFL.txt` and `WorkSans-OFL.txt`, as the OFL requires.

They are bundled here so `build.py` renders identically on any machine, with no
network access and nothing to install.
